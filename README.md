# Troll Calculator 🤪

A dark-themed, mobile-friendly calculator that accepts numbers in multiple numeral systems… then randomly outputs the result in a **different** one just to mess with you!

## ✨ Features

- **7 Numeral Systems Supported** – Input numbers in:
  - Decimal (0–9)
  - Binary (0, 1)
  - Octal (0–7)
  - Hexadecimal (0–9, A–F)
  - Roman (I, V, X, L, C, D, M)
  - Persian (۰–۹)
  - Chinese (〇–九)

- **Dynamic Keypad** – The on-screen keypad adapts to the selected numeral system, showing only valid characters.

- **Troll Mode** 🤪 – After each calculation, the result is displayed in a **random numeral system different from the input system**. The calculator then automatically switches to that new system so you can continue calculating—and keep getting trolled!

- **Power Button** ⏻ – Turn the calculator on/off. When powered on, it starts with `0` ready for immediate use.

- **Dark Theme** 🌙 – Easy on the eyes, perfect for late-night coding sessions.

- **Fully Responsive** 📱 – Works seamlessly on desktop, tablet, and mobile devices.

## 🎯 How It Works

1. **Select** your input numeral system from the dropdown.

2. **Enter** numbers using the dynamic keypad.

3. **Choose** an operation (+, −, ×, ÷).

4. **Press** `=` to calculate.

5. **Watch** the result appear in a *different* numeral system (troll!).

6. **Continue** calculating—the calculator automatically switches to the new system.

### Example

- Input: `10` (Decimal) + `20` (Decimal)
- Result might appear as: `11110` (Binary), `36` (Octal), `1E` (Hex), `XXX` (Roman), `۳۰` (Persian), or `三十` (Chinese) – completely random!
